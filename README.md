# 재고 약도 (GitHub Pages + 구글 앱스 스크립트)

- **보기**: 주소만 있으면 누구나 (로그인 없음)
- **수정**: 구글 시트의 `수정권한` 시트에 적힌 코드를 가진 사람만
- 데이터는 관리자 구글 드라이브의 구글 시트에 저장됩니다.

## 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 (GitHub Pages로 공개) |
| `config.js` | 앱스 스크립트 주소 한 줄 (배포 후 직접 입력) |
| `Code.gs` | 저장 서버 코드 (구글 앱스 스크립트에 붙여넣기) |

## 1. 저장 서버 만들기 (구글 시트 + 앱스 스크립트) — 약 5분
1. 구글 드라이브에서 **새 구글 시트**를 만들고 이름을 `재고 약도 데이터`로 바꿉니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 `Code.gs` 내용을 붙여넣고 저장합니다.
4. 위쪽 함수 선택에서 **setup**을 고르고 **실행**합니다. 처음 한 번 권한 허용 창이 뜨면 허용합니다.
   - ("확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동**을 누르면 됩니다. 본인이 만든 스크립트라 괜찮습니다.)
5. 시트로 돌아가면 `docs`, `history`, `log`, `수정권한` 시트가 생겨 있습니다.
   - `수정권한` 시트에 **관리자 코드**가 하나 만들어져 있습니다. 수정할 사람을 한 줄씩 추가하세요. (A열 이름, B열 코드)
   - 사람을 빼려면 그 줄만 지우면 됩니다.
6. 앱스 스크립트에서 **배포 → 새 배포** → 유형 **웹 앱**:
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ("Google 계정이 있는 모든 사용자" 아님)
7. **배포**를 누르고 나오는 **웹 앱 URL**(…/exec)을 복사합니다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로)

## 2. 앱 공개 (GitHub Pages)
1. 이 저장소의 `config.js`를 열고 연필(편집)을 눌러 따옴표 안에 웹 앱 URL을 붙여넣고 저장(Commit)합니다.
2. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save.
3. 1~2분 뒤 `https://gregwkd1000-lang.github.io/hangang/` 주소로 열립니다. 이 주소를 공유하면 됩니다.

## 3. 지금 데이터 옮기기 (한 번만)
1. **지금 쓰던 Claude 재고 약도 앱**에서 위쪽 저장 표시(“저장됨”)를 누르고 **전체 백업 파일 받기**.
2. **GitHub 주소의 앱**에서 위쪽 “보기 전용”을 누르고 **수정 코드 입력** → 관리자 코드 입력.
3. 다시 위쪽 저장 표시를 누르고 **백업 파일 불러오기** → 1번 파일 선택 → 불러오기.
4. 구글 시트 `docs` 시트에 탭 14개가 생기면 끝입니다.

## 사용
- 위쪽 저장 표시를 누르면 수정 코드 입력·지우기, 백업 받기·불러오기를 할 수 있습니다.
- 다른 사람이 고친 내용은 10~15초 안에 자동으로 보입니다.
- 두 사람이 같은 탭을 동시에 고치면, 각자 바꾼 칸만 합쳐서 저장합니다. (같은 칸을 동시에 고치면 나중에 저장한 쪽)
- 누가 언제 고쳤는지는 시트의 `log`에 남습니다.

## 나중에 카카오클라우드로 옮길 때
- `index.html`은 그대로 정적 호스팅에 올립니다.
- `Code.gs`가 하는 일(아래 API)을 서버로 새로 만들고 `config.js` 주소만 바꾸면 됩니다.
- 데이터는 앱의 **전체 백업 파일**로 옮깁니다.

| 요청 | 내용 |
|---|---|
| `GET ?action=ver` | 탭별 버전 `{vers:{탭:버전}}` |
| `GET ?action=all` / `?action=docs&cids=a,b` | 탭 데이터 `{docs:{탭:{v,data}}}` |
| `GET ?action=hist&cid=탭&limit=n` | 지난 기록 목록 |
| `POST {action:"auth",code}` | 코드 확인 `{ok,name}` |
| `POST {action:"set",cid,code,baseV,data}` | 저장 (버전이 다르면 `{conflict,v,data}`) |
| `POST {action:"hist"/"histBulk",…}` | 지난 기록 저장 |
